# 发票抬头查询

该目录提供“发票抬头查询”接口的多语言调用示例。

## 请求参数

- `name`：发票抬头名称

## 示例中使用的环境变量

- `INVOICE_NAME`
  默认值：`上海奇伢信息科技有限公司`
- `API_URL`

## 腾讯云市场默认地址

- `https://service-rf059r1j-1258478321.sh.apigw.tencentcs.com/release/getInvocieInfo`

## 说明

- 腾讯云市场示例使用 HMAC 鉴权
- 阿里云市场示例使用 `APPCODE` 鉴权
- 阿里云市场示例中的 `API_URL` 是占位地址，使用前请替换为实际接口地址
