# 发票抬头查询

Request field:

- `name`: invoice title name

Environment variables used by the samples:

- `INVOICE_NAME` default: `上海奇伢信息科技有限公司`
- `API_URL`

Default Tencent URL in the samples:

- `https://service-rf059r1j-1258478321.sh.apigw.tencentcs.com/release/getInvocieInfo`

Aliyun samples use a placeholder domain by default. Replace `API_URL` with the actual Aliyun marketplace endpoint before running.
