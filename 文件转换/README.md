# 文件转换

Request fields:

- `fileName`: original file name
- `url`: source file URL
- `callbackUrl`: optional callback URL

Environment variables used by the samples:

- `FILE_NAME` default: `demo.docx`
- `FILE_URL`
- `CALLBACK_URL` default: empty
- `API_URL`

Default Tencent URL in the samples:

- `http://service-9jiloqcv-1258478321.sh.apigw.tencentcs.com/release/fileConvert`

Aliyun samples use a placeholder domain by default. Replace `API_URL` with the actual Aliyun marketplace endpoint before running.
